# The cast rig, release 2 (0.12.0): the editor

> **For agentic workers:** REQUIRED SUB-SKILL: Use the subagent-driven-development skill (recommended) or the executing-plans skill to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the editor as a 32x48 chibi on the 0.11.0 rig (a suit, glasses, a briefcase in the back hand, the
visit's prop in the front hand), walked, turned at the door, given a few waiting moments and a verdict (a nod or a
sigh) by the cast driver, standing in front of the bed at (205, 90); then retire the 0.10 editor maps, the
code-drawn visit props and the legacy frames they were cut from.

**Architecture:** The rig gains a second head (`EDITOR_HEAD`, its own eye drawings with the lens rims) and the parts
the editor's poses name (a suit torso, suit sleeves, the briefcase baked into the back-arm sleeves); `rig/frames.ts`
picks the face art by the pose's head and memoizes each pose's front-hand cell (`frontHand`), where render draws the
visit's prop as a small cast frame of its own (`rig/props.ts`). The sprite cache gains an `editor` palette (the
mangaka's leg parts recoloured to the suit). `castPlay.ts` gains an `editor` track (seat 4 of the idle schedule),
per-character transitions and the `offer` reaction; `render.ts` draws the editor as one `drawImage` (plus the prop
and the `!`), mirrored facing right. A switch (`RIG_LIVE.editor`, on in a dev build with `?rig`) keeps the 0.10
editor drawing until the set is complete, as 0.11.0 did for the mangaka.

**Tech Stack:** React 19, TypeScript (`erasableSyntaxOnly`, `verbatimModuleSyntax`, `noUnused*`), Vite, Vitest (node
and happy-dom), Zustand, oxlint; `scripts/spriteSheet.ts` (vite-node + sharp) for the contact sheet.

**Spec:** `docs/plans/2026-10-11-editor-rig-design.md` (binding), on `docs/plans/2026-10-09-cast-rig-design.md`.

## Decisions this plan makes (from the code it read)

1. **The briefcase is baked into the back-arm sleeve parts.** The rig's `prop` layer joins the front arm's hand only
   (`JOIN.prop` is `'hand'` on `armFront`, `rig/types.ts`), and the spec puts the case in the back hand, so each
   suit sleeve the back arm uses (`arm-r-suit-case`, `-fwd`, `-back`) carries the case under its fist in one map. The
   `armBack` layer paints first, so a stepping leg passes in front of the case, the depth the 0.10 frames had.
2. **The visit's props are cast frames in PAL keys, drawn in the `editor` palette**, not in the 0.10 `PROP_PAL`: the
   envelope's and letter's lines use `w` (`#b8b2a5`, PAL's since 0.11.0), the contract's seal `M` (`#c0392b` for
   the old `#e5484d`), the trophy's cup `X` (`#f5b700`) and its base the new `D`. `PROP_PAL` retires with them; its
   colours stay literal in `render.ts` (`PROP_PAPER`, `PROP_LINE`, the desk's `#8b5a2b`, the glyphs' `#e5484d`).
3. **PAL gains `D`/`d`** (`#6d4c33`/`#4e3622`, the 0.10 `F`/`f` colours under their own keys) for the briefcase's
   leather, because the editor's palette remaps `F`/`f` to the suit (`G`/`g`) and `O`/`o` to black (`E`), exactly
   as the 0.10 `recolour('FfOo', 'GgEE')` did, so the mangaka's leg parts dress the editor unchanged.
4. **The glasses' rims are `L`, not `P`.** The rims inside the eye slot must be face keys (`headRules`), so the whole
   frame is drawn in the outline key: the top edge on head row 9, the sides at head cols 4, 10, 13 and 19 through
   rows 10-13 (inside `EDITOR_EYES`), the bottom edge on row 14, the bridge on row 11 at cols 11-12. `P` stays in
   `PAL` unused (its colour `#6b6b78` is `roomArt.ts`'s `METAL_LIGHT` too). The 0.10 P-lightness test retires with the
   0.10 frames.
5. **The verdicts are part poses, not key frames.** A nod is the head two rows lower (`dy: 2`); a sigh is the torso
   one then two rows lower with the legs nudged up by as much (the feet stay on row 47; the torso paints over the
   legs' tops) and the eyes closed, the mouth frowning. Part poses keep the front hand's anchor, so the visit's prop
   stays in the hand through a verdict; a key frame would lose it. `poseRules` passes both (checked by running the
   assembler on the standing body with those nudges).
6. **The `offer` reaction fires when the offer comes into view**, not when `pendingOffer` is first set: the sim sets
   `pendingOffer` in the same tick as `pendingResult` (`engine.ts`, the result's tick), when the editor is still
   walking in, so a cue on "null to set" could never play. `offerShown(g) = pendingOffer && !pendingResult`; the
   cue fires on `!offerShown(before) && offerShown(after)` (the result dismissed with the offer behind it, or an
   offer set with no result in front). Priority: missed, bad-poll, good-poll, offer, level-up, late (a good poll and
   an offer in one change both nod the editor; the mangaka's cheer wins).
7. **The editor walks y first on the way in and x first on the way out** (`legs` `'yx'` then `'xy'`): from the door
   (250, 69) down to y 90 beside the door, then left along the floor to x 205, so the frame (drawn after the bed)
   crosses the bed in front of it, never through its headboard; leaving, back along the floor then up. Both orders
   sum the same 45 + 21 = 66 px: `EDITOR_WALK_MS` 1650.
8. **The editor's spot box in the furniture tests is the frame's painted width**, `[205, 235, 90, 137]` (cols 0-30;
   col 31 is clear in every editor pose, pinned in `rigPoses.test`), so the loft's floor plant (x 236-248) clears it.
   `render.test`'s "keeps the cat clear" loses the editor's box: the spec accepts the editor standing in front of the
   napping cat (drawn after it).
9. **The dev preview plays only the character's own animations:** `?rig=editor-glasses` plays on the editor alone and
   `?rig=stand-look` never on him (`previewFits`), so the mangaka never wears the editor's head.
10. **`ANCHOR_HEAD` and `faceRules` stay in `spriteCore.ts`** for `scripts/pixelate.ts`'s `--sprite` graft (every
    sprite manifest entry is retired, but `npm run art -- sprite/<name>` regenerates one by name, and `art.test`
    checks the graft's note), with their tests moved onto `ANCHOR_HEAD` itself; `sprites.ts` stops re-exporting them.
    `RUN_CAPS` keeps the cat's rows only.
11. **The sheet drops row F and the editor half of row H at Task 4**, when the `editor-*` blocks (each strip beside
    the base's `EDITOR_IDLE`/`EDITOR_WALK`) and the rig editor's walk strip take their place, so `npm run sprites`
    never breaks when the working tree loses the 0.10 editor exports at the switch.
12. **The idle schedule's fifth seat is 4** (`nextIdle(day, 4, n)`): the editor's loops start at `now - 4 x PHASE_MS`
    like any seat, which costs nothing and keeps one rule. Verified by running the code: `nextIdle(12, 4, 0)` is
    `{ gapMs: 7617, pick: 58763 }` (58763 % 3 = 2), `nextIdle(12, 4, 1).gapMs` is 13451.
13. **The `!` above a visiting editor stays**, code-drawn (4 fills) in the rig's mark slot (frame col 28, the head's
    top row, bobbing a row every 16 frames as before), so the pending card's signal survives the prop's move into the
    cache.
14. **The editor stays at the spot until his verdict has played (controller ruling).** Dismissing a result sets
    `pendingResult` null; with no offer behind it `sceneReasonOf` is `'none'`, and the same store change re-plans
    the actors, sending him to the door; on the next loop step `stepActors` runs before `stepCast`, so the driver
    would find him `'walking'`, drop the cue, and `editor-leave`'s `switchBase` would clear anything queued: no sigh
    ever, and a nod only when an offer follows. So `Actor.holdMs` (a number, 0 by default, presentation only):
    `stepActors` leaves a held actor where it is, its state unchanged, and counts the hold down by dt (a settle and
    reduced motion clear it); `StudioScene`'s reaction subscription, which runs synchronously on the store change
    before React re-renders and before the plan effect, sets `actors.editor.holdMs` to `verdictHoldMs(kind, editor)`
    (`castPlay.ts`: the verdict's `animLength` plus `VERDICT_HOLD_SLACK_MS` 50, the one loop step that walks the
    actors before the driver takes the cue, while he is standing; 0 otherwise), so the driver still sees him standing
    when it takes the cue and plays `editor-nod`/`editor-sigh`; when the hold runs out he walks out through
    `editor-leave` as usual. Never the sim: the desk card and the clock are untouched. Built in Task 7 (the scene
    wiring, where the subscription lives), with its unit and integration tests. Verified by running the hold's
    arithmetic against the player: a 1250 ms hold (the sigh's 1200 + 50) at 41 ms steps releases him on the 32nd
    step (1312 ms), after the sigh, taken on the first step, ended at 1241.

```ts
import { assemblePose, placeLayers } from './assemble'
import { FACE_ART, FACE_BY_MOOD } from './head'
import { PARTS } from './parts'
import { POSES } from './poses'
import type { PoseId } from './poses'
import type { CastFrame, Face, FaceArt, Mood, PartPose, Point } from './types'

/** The face art each head part takes, by the part's name (the editor's head has its own eyes, with the lens rims). */
const FACE_ART_BY_HEAD: Readonly<Record<string, FaceArt>> = { head: FACE_ART }

/** The face art for a part pose: its head part's. */
export function faceArtOf(pose: PartPose): FaceArt {
  const art = FACE_ART_BY_HEAD[pose.head.part]
  if (!art) throw new Error(`no face art for the head ${pose.head.part}`)
  return art
}

const hands = new Map<PoseId, Point | null>()

/**
 * Where a part pose's front hand is in its frame (the front arm's hand anchor), null for a key frame or a pose with no
 * front arm: the visit's prop is drawn there. Found once per pose and kept, so render allocates nothing.
 */
export function frontHand(id: PoseId): Point | null {
  let p = hands.get(id)
  if (p === undefined) {
    const pose = POSES[id].pose
    const arm = pose.kind === 'parts' && pose.armFront ? placeLayers(pose, PARTS).get('armFront') : undefined
    const hand = arm?.part.anchors.hand
    p = arm && hand ? { x: arm.at.x + hand.x, y: arm.at.y + hand.y } : null
    hands.set(id, p)
  }
  return p
}
```

```ts
/** A head with a face: the eyes and the mouth in its slots, the mark beside the hair (the sheet, the portrait); the rig head in its art by default. */
export function headWith(face: Face, head: HeadPart = HEAD, art: FaceArt = FACE_ART): SpriteMap {
  const rows = stampFace(head, art, face).map((row) => row.split(''))
  if (face.mark !== 'none') {

    art.marks[face.mark].forEach((row, r) => {

    })
  }
  return rows.map((row) => row.join(''))
}
```

```ts
// The cast driver (0.11.0; the editor since 0.12.0): each loop step it turns every rig-drawn actor's state (actors.ts)
// into a pose on the actor (`Actor.pose`) through the animation player: the base loop for the state, the transition
// between two states, the idle moments the seeded schedule picks and the reactions the snapshot's cue brings. The
// tracks are mutated in place, like the actor table; the rules they follow are pure functions, tested alone. No
// clock: StudioScene passes its scene time.
import { LOW_STAMINA_THRESHOLD } from '../../sim'
import { RIG_LIVE } from './actors'
import type { Actor, ActorState, ActorTable } from './actors'
import { advance, enqueue, interrupt, poseAt, settle, startPlayer, switchBase } from './animation'
import type { Anim, PlayerState } from './animation'
import { nextIdle } from './idleSchedule'
import type { ReactionCue, ReactionKind } from './reactions'
import { ANIMS } from './rig/anims'
import type { AnimId } from './rig/anims'
import type { PoseId } from './rig/poses'

export type CastWho = 'mangaka' | 'assistant' | 'editor'

/** What picks a base loop besides the state: drawing with the clock running, the chapter late, the manuscript ready. */
export interface CastContext { working: boolean; late: boolean; ready: boolean }

/** The base loop for a character in a state, or null when it is not drawn (away, hidden; the editor only stands and walks). */
export function baseAnimFor(who: CastWho, state: ActorState, c: CastContext): AnimId | null {
  if (who === 'editor') return state === 'standing' ? 'editor-stand' : state === 'walking' ? 'editor-walk' : null
  switch (state) {
    case 'seated': return c.working ? (c.late && who === 'mangaka' ? 'seat-draw-late' : 'seat-draw') : 'seat-idle'
    case 'standing': return who === 'mangaka' ? (c.ready ? 'stand-ready' : 'stand') : null
    case 'walking': return who === 'mangaka' ? 'walk' : null
    case 'sleeping': return who === 'mangaka' ? 'sleep' : 'doze'
    default: return null
  }
}

/**
 * The transition between two states for a character, or null: the people down into the chair and up out of it, into
 * bed and out of it; the editor's turn at the spot on arriving and back toward the door on leaving.
 */
export function transitionFor(who: CastWho, from: ActorState, to: ActorState): AnimId | null {
  if (who === 'editor') {
    if (from === 'walking' && to === 'standing') return 'editor-arrive'
    if (from === 'standing' && to === 'walking') return 'editor-leave'
    return null
  }
  if (from === 'walking' && to === 'seated') return 'sit-down'
  if (from === 'seated' && to === 'walking') return 'stand-up'
  if (from === 'walking' && to === 'sleeping') return 'lie-down'
  if (from === 'sleeping' && to === 'walking') return 'get-up'
  return null
}

const STAND_POOL: readonly AnimId[] = ['stand-look', 'stand-sip']
const SEAT_POOL: readonly AnimId[] = ['seat-stretch', 'seat-sip', 'seat-flip']
const TIRED_POOL: readonly AnimId[] = ['seat-rub', 'seat-sip']
/** The editor's waiting moments: pushing up the glasses, checking the watch, a glance at the manuscript pile. */
const EDITOR_POOL: readonly AnimId[] = ['editor-glasses', 'editor-watch', 'editor-glance']
const NO_POOL: readonly AnimId[] = []

/**
 * The idle moments a base loop picks from: standing, a look around or a sip; at the desk, a stretch, a sip or a page
 * flipped, or, tired, rubbing the eyes; the editor waiting, his own three.
 */
export function idlePool(base: AnimId, tired: boolean): readonly AnimId[] {
  if (base === 'stand') return STAND_POOL
  if (base === 'seat-draw' || base === 'seat-idle') return tired ? TIRED_POOL : SEAT_POOL
  if (base === 'editor-stand') return EDITOR_POOL
  return NO_POOL
}

/** Every idle moment (the pools' animations): a reaction cuts one short; it waits behind a transition or another reaction. */
export const IDLE_MOMENTS: ReadonlySet<string> = new Set<AnimId>([...STAND_POOL, ...SEAT_POOL, ...TIRED_POOL, ...EDITOR_POOL])

/**
 * The animation a reaction plays for a character in a state, or null (the 0.11.0 plan's decision 7; the editor's
 * verdicts, 0.12.0: a nod on an offer or a good poll, a sigh on a bad one, only standing at the spot).
 */
export function reactionAnim(kind: ReactionKind, who: CastWho, state: ActorState): AnimId | null {
  const seated = state === 'seated'
  const standing = state === 'standing'
  if (who === 'editor') {
    if (!standing) return null
    return kind === 'offer' || kind === 'good-poll' ? 'editor-nod' : kind === 'bad-poll' ? 'editor-sigh' : null
  }
  if (who === 'assistant') return kind === 'good-poll' && seated ? 'seat-cheer' : null
  switch (kind) {
    case 'good-poll':
    case 'level-up': return standing ? 'stand-cheer' : seated ? 'seat-cheer' : null
    case 'bad-poll': return standing ? 'stand-slump' : seated ? 'seat-slump' : null
    case 'late': return seated ? 'seat-panic' : null
    case 'missed': return seated ? 'seat-tear' : null
    case 'offer': return null
  }
}

/** Whether a dev preview animation is the character's own: the editor plays only `editor-*`, and no one else does. */
export function previewFits(who: CastWho, anim: Anim): boolean {
  return anim.id.startsWith('editor-') === (who === 'editor')
}

/** One character's animation: its player, the state it last saw, the last cue it took, its idle schedule. */
export interface Track {
  player: PlayerState<PoseId> | null
  state: ActorState
  cue: number
  /** The game day the count is for, and the moments counted that day (the schedule's seed). */
  idleDay: number
  idleN: number
  /** When the next idle moment fires, on the scene clock; -1 until it is scheduled. A new day never moves it. */
  nextIdleAt: number
}

export interface CastPlay { readonly mangaka: Track; readonly assistants: readonly [Track, Track, Track]; readonly editor: Track }

function newTrack(): Track {
  return { player: null, state: 'hidden', cue: 0, idleDay: -1, idleN: 0, nextIdleAt: -1 }
}

export function newCastPlay(): CastPlay {
  return { mangaka: newTrack(), assistants: [newTrack(), newTrack(), newTrack()], editor: newTrack() }
}

/** What the driver reads each step besides the actor table (StudioScene fills one object in place). */
export interface CastInput {
  day: number
  working: boolean
  late: boolean
  ready: boolean
  stamina: number
  assistants: readonly { stamina: number }[]
  reaction: ReactionCue | null
  /** A dev build's `?rig=<animation>`: played over every base of its posture on its own character whenever nothing else plays. */
  preview: AnimId | null
}

/** How far apart the seats' loops start, so the assistants' pens never move in step. */
export const PHASE_MS = 150
/** The editor's seat in the idle schedule and the phase (the mangaka is 0, the assistants 1-3). */
export const EDITOR_SEAT = 4

const ctx: CastContext = { working: false, late: false, ready: false }

function baseOf(who: CastWho, a: Actor, input: CastInput): AnimId | null {
  ctx.working = input.working
  ctx.late = input.late
  ctx.ready = input.ready
  return baseAnimFor(who, a.state, ctx)
}

/** The stamina the idle pool reads for a seat: the mangaka's, an assistant's own, the editor's never low. */
function staminaOf(who: CastWho, seat: number, input: CastInput): number {
  if (who === 'mangaka') return input.stamina
  if (who === 'assistant') return input.assistants[seat - 1]?.stamina ?? 100
  return 100
}

function stepTrack(t: Track, a: Actor, who: CastWho, seat: number, live: boolean, input: CastInput, now: number, reduced: boolean): void {
  if (!live) {
    a.pose = ''
    return
  }
  const id = baseOf(who, a, input)
  if (id === null) {
    t.player = null
    t.state = a.state
    a.pose = ''
    return
  }
  const base = ANIMS[id]
  if (!t.player) {
    t.player = startPlayer(base, now - seat * PHASE_MS)
    t.cue = input.reaction?.id ?? t.cue
  } else if (base !== t.player.base) {
    // a new base keeps the seat's phase (so the assistants' pens never fall into step); a transition starts now
    const tr = reduced ? null : transitionFor(who, t.state, a.state)
    t.player = switchBase(t.player, base, tr === null ? null : ANIMS[tr], tr === null ? now - seat * PHASE_MS : now)
  }
  t.state = a.state
  // end what played out since the last step first, so nothing below sees a finished one-shot as still playing
  t.player = advance(t.player, now)
  if (input.reaction && input.reaction.id !== t.cue) {
    t.cue = input.reaction.id
    const r = reduced ? null : reactionAnim(input.reaction.kind, who, a.state)
    if (r !== null) {
      // a reaction cuts an idle moment short; it waits behind a transition or another reaction
      const playing = t.player.over?.anim.id
      t.player = playing !== undefined && IDLE_MOMENTS.has(playing) ? interrupt(t.player, ANIMS[r], now) : enqueue(t.player, ANIMS[r], now)
    }
  }
  if (reduced) {
    a.pose = base.steps[0].pose
    return
  }
  // a new game day restarts the count (the schedule's seed), never the wait: days turn every 220-1000 ms while the
  // clock runs, and the shortest wait is 6 s
  if (t.idleDay !== input.day) {
    t.idleDay = input.day
    t.idleN = 0
  }
  if (t.nextIdleAt < 0) t.nextIdleAt = now + nextIdle(input.day, seat, t.idleN).gapMs
  if (now >= t.nextIdleAt) {
    const pool = idlePool(id, staminaOf(who, seat, input) < LOW_STAMINA_THRESHOLD)
    if (pool.length && !t.player.over) t.player = enqueue(t.player, ANIMS[pool[nextIdle(input.day, seat, t.idleN).pick % pool.length]], now)
    t.idleN++
    t.nextIdleAt = now + nextIdle(input.day, seat, t.idleN).gapMs
  }
  const preview = input.preview === null ? null : ANIMS[input.preview]
  if (preview && preview !== base && preview.posture === base.posture && previewFits(who, preview) && !t.player.over) {
    t.player = enqueue(t.player, preview, now)
  }
  a.pose = poseAt(t.player, now)
}

/**
 * One loop step for the whole cast at scene time `now` (the mangaka, the three assistants' seats and, while his switch
 * is on, the editor at the fifth seat; the cat keeps its 0.10 frames); `reduced` (reduced motion) holds every base's
 * first step.
 */
export function stepCast(play: CastPlay, table: ActorTable, input: CastInput, now: number, reduced: boolean): void {
  stepTrack(play.mangaka, table.mangaka, 'mangaka', 0, true, input, now, reduced)
  for (let i = 0; i < 3; i++) stepTrack(play.assistants[i], table.assistants[i], 'assistant', i + 1, true, input, now, reduced)
  stepTrack(play.editor, table.editor, 'editor', EDITOR_SEAT, RIG_LIVE.editor, input, now, reduced)
}

function settleTrack(t: Track, a: Actor, who: CastWho, seat: number, live: boolean, input: CastInput, now: number): void {
  if (!live) {
    a.pose = ''
    return
  }
  const id = baseOf(who, a, input)
  t.player = id === null ? null : startPlayer(ANIMS[id], now - seat * PHASE_MS)
  t.state = a.state
  t.cue = input.reaction?.id ?? t.cue
  t.idleDay = -1
  t.nextIdleAt = -1
  a.pose = id === null ? '' : ANIMS[id].steps[0].pose
}

/** Everyone on their base loop from now (a mount, a loaded save): no transition, the waiting cue taken as seen. */
export function settleCast(play: CastPlay, table: ActorTable, input: CastInput, now: number): void {
  settleTrack(play.mangaka, table.mangaka, 'mangaka', 0, true, input, now)
  for (let i = 0; i < 3; i++) settleTrack(play.assistants[i], table.assistants[i], 'assistant', i + 1, true, input, now)
  settleTrack(play.editor, table.editor, 'editor', EDITOR_SEAT, RIG_LIVE.editor, input, now)
}

/**
 * The window shown again: every transition and moment jumps to its end, each base going on from now at its seat's
 * phase (so the assistants stay `PHASE_MS` apart), and every idle wait is re-armed from the next step.
 */
export function resumeCast(play: CastPlay, now: number): void {
  const tracks = [play.mangaka, ...play.assistants, play.editor]
  for (let seat = 0; seat < tracks.length; seat++) {
    const t = tracks[seat]
    if (t.player) t.player = settle(t.player, now, now - seat * PHASE_MS)
    t.nextIdleAt = -1
  }
}
```
